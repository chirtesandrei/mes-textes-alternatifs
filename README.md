# Mes Textes alternatifs

Relisez et corrigez manuellement les textes alternatifs de la bibliothèque.

- Fiche, téléchargement et empreinte SHA-256 : https://mesplugins.fr/plugins/mes-textes-alternatifs/
- Toutes les extensions MesPlugins.fr : https://mesplugins.fr/plugins/

## Ce que fait l’extension

Depuis Outils > Mes Textes alternatifs, relisez 20 images par page, saisissez une description ou marquez explicitement une image décorative. Aucun service d’IA ni envoi d’image.

## Limites

Modifie les métadonnées de la bibliothèque, pas le HTML déjà enregistré dans les articles ou les constructeurs. Une image peut exiger des descriptions différentes selon la page. Aucune conformité d’accessibilité garantie.

Première version réservée aux installations WordPress simples : l’activation est refusée en multisite.

## Installation

1. Téléchargez le ZIP depuis https://mesplugins.fr/plugins/mes-textes-alternatifs/ et vérifiez son empreinte.
2. Dans WordPress : Extensions > Ajouter > Téléverser une extension.
3. Activez puis ouvrez Outils > Mes Textes alternatifs.

## Mises à jour

L’administration, le cron et WP-CLI consultent un manifeste fixe de mesplugins.fr, sans identifiant du site. Définir `MESPLUGINS_DISABLE_UPDATE_CHECK` à `true` dans wp-config.php désactive cette vérification. Aucune télémétrie.
